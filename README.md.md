# MindCare Assess

A student-project demonstration website for exploring cognitive wellbeing through original educational activities.

## Files

- `index.html` — website structure and content
- `style.css` — styling and responsive layout
- `script.js` — navigation, educational activities, session history, and demo report export

## Run locally

Open `index.html` in a modern web browser.

## Publish with GitHub Pages

1. Upload all three website files to the root of a GitHub repository.
2. Open the repository's **Settings**.
3. Select **Pages**.
4. Under the build/deployment section, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish the site.

## Important note

This is a student demonstration project, not a medical device or clinical assessment. The activities are original educational exercises and are not validated clinical measures. The demo does not reproduce official MoCA or MMSE test materials, and it does not provide medical diagnosis.
